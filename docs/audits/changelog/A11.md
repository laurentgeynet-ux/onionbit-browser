## A11 — browser glue : `cache.c`/`capi.c`/`web.cc`/`timeout.cc` (apply)

Corrections de parité sémantique sur `dillo-net` (rapport
`docs/audits/reports/A11_browser-glue.md`) — le lot le plus
dense de la phase 9, tout le contenu cache/CAPI est concerné :

- **D1 — redirect bloquée injouable (wire-visible)** : `entry->Location`
  est posé **avant** le test domainrc/dpi (verbatim `cache.c:810`).
  Une 30x bloquée garde `location` sans `CA_Redirect` →
  `Cache_provide_redirection_blocked_page` sert la page « Dillo
  blocked a redirection » au lieu de partir en dispatch/abort.
- **D2 — client sauté après dequeue (wire-visible, le plus grave)** :
  dans la boucle `process_queue`, `i = idx + 1` était posé
  inconditionnellement après `clients.remove(idx)` — quand le client
  n'est pas réinséré, le suivant glisse à `idx` et était sauté
  (≥2 clients/même URL : un sur deux jamais servi). `i = idx` quand
  non réinséré, `idx + 1` seulement après réinsertion ≙ `--i`/`++i`
  amont (`cache.c:1429-1432,1471-1472`).
- **D3 — `Set-Cookie` multi-clients** : le `break` externe supprimé —
  un client tiers non autorisé n'interrompt plus le scan ; on ne
  stoppe qu'après un `cookies_set` réel (`cache.c:893-919`).
- **D4 — `IsCached` mappé, pas brut** (`request_permitted`) :
  `cache_get_flags` brut testait `CA_GotHeader` (0x1) sous le nom
  `CAPI_IsCached` ; remplacé par `capi_get_flags` mappé
  (`IsCached` ⇔ entrée existante — `capi.c:379,501-517`). Une
  sous-requête vers une entrée en cours n'est plus soumise à
  domainrc.
- **D5 — `TypeMismatch`→`AbortEntry` tous clients** : calcul hoisté
  dans le bloc de détection (une fois, comme amont `cache.c:1345`)
  au lieu d'être recomputé sous `WEB_ROOT_URL` — le `set_msg` reste
  root-only mais l'abort s'applique à tout client sans callback.
- **D6 — `hits` sur hit seul** : le miss interne
  (`about:cache`/`about:dicache` première charge) n'incrémente plus
  `Hits` — `cache.c:496` branche `entry` trouvée seule.
- **D7 — `auth` vs `busy`** : `entry->Auth` n'est consommé que si
  `!auth_busy` (amont `cache.c:1226` arme le timeout avant de vider) ;
  si occupé, le défi reste sur l'entrée (rejouable) + warn « caught
  busy ».
- **D8 — `conn_abort_by_url` premier match** : `break` amont
  (`capi.c:214`) — collecte → `find` + un seul abort.
- **D9 — préfixes ASCII-CI** : `url_uses_dpi` (`http:`/`https:`/
  `about:`/`dpi:/`) et `dispatch_by_type` (`image/`) passent en
  `eq_ignore_ascii_case` ≙ `dStrnAsciiCasecmp` — `HTTP://x` n'est
  plus routé `proto.http`, `IMAGE/PNG` non-root dispatché.
- **D10 — `E2EQuery` sur `web` partagé** : `Rc::get_mut` quand
  exclusif ; sinon l'effet observable requis (entrée cache retirée
  avant réouverture) est appliqué via `cache_entry_remove_by_url` —
  un reload `dpi:/` hors vsource ne sert plus l'entrée périmée.
- **D11 — `datastr` octets** : `Option<Vec<u8>>` tronqué au premier
  NUL ≙ `dStrdup` — le payload binaire dpi n'est plus altéré par
  `from_utf8_lossy`.
- **D12 — doc `timeout_repeat`** : corrigée — amont utilise
  `Fl::add_timeout` (identique à `add`), pas `repeat_timeout`.
- **D13 — `pending_abort` drainé après `OP_START`** : le CCC résout
  `conn` depuis `d1` quand le `local_key` n'est pas encore posé —
  un abort demandé pendant l'armement n'est plus perdu.
- **D14 — `dStr_shorten`** : `about:cache` coupe l'URL au milieu
  (28 + `...` + 29) via `dlib::Dstr::shorten` au lieu de
  `chars().take(60)`.
