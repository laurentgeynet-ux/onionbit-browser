## A01 — I/O & HTTP (apply)

Corrections de parité sémantique sur `dillo-net` (rapport
`docs/audits/reports/A01_io-http.md`) :

- **D1 — `Proxy-Authorization` initiale : non-bug.** Le bloc
  `http_proxyuser → base64` est *commenté* amont
  (`http.c:131-136`, « security problem… disabled ») — le rapport
  avait lu du code mort. Rien à activer ; l'envoi par défi 407 est
  déjà en place.
- **D2 — contre-pression `IoEvent` (comportementale)** : le canal
  événementiel passe de `unbounded_channel` à `channel(8)` — amont
  draine chaque `IORead` **synchrone** (la fenêtre TCP fait la
  contre-pression) ; un canal infini accumulait en mémoire quand le
  consommateur traînait. `read_task`/`write_task` émettent
  désormais en `send().await` : la lecture suspendue referme la
  fenêtre TCP, fidèle au drain amont. Les événements de fin de vie
  (`Eof`/`ReadErr`) restent livrés avant retour de tâche.
- **D3 — commentaire `proxy_reply_recv` (doc)** : cite désormais
  `dStr_append(reply, dbuf->Buf)` (strlen amont, `Size` ignoré) —
  la borne `min(size, buf.len)` conservée reste l'équivalent sûr.
- **D4 — `assert(sd)` amont** : `debug_assert!` ajouté en tête de la
  branche `(2,FWD)` de `http_ccc` — état impossible = panic debug,
  release dégrade en drop silencieux (`dReturn_if_fail` porté).
- **D5 — diagnostic CONNECT proxy** : sur `OpAbort` 2F, la réponse
  partielle `https_proxy_reply` est loguée (« CONNECT through proxy
  failed. Full reply not received:\n… », `(nothing)` si vide) —
  verbatim `http.c` amont.

Tests ajoutés : `event_channel_is_bounded` (`try_send` plein à
capacité → `Err`).

## A01 — passe 2 (apply)

8 déviations corrigées sur `dillo-net` (+ câblage `dillo`) :

- **D6 — flags `ca_flags` control (wire-visible)** : `GOT_HEADER`
  `0x10`→`0x1`, `GOT_LENGTH` `0x20`→`0x4` (≙ `cache.h` amont) — la
  commande `load` redevenait un `rawload` (corps re-parsé comme
  réponse brute) ; `dump`/`hdump` réinjectent désormais le corps
  directement.
- **D7 — HSTS jamais honoré (fonctionnel)** : seam `cert_clean`
  câblée — nouveau `tls::CertRegistry` (`Rc<RefCell>` partagé entre
  `TlsEngine`s ≙ `Tls_servers` global amont : le verdict cert d'une
  connexion pilote les suivantes) exposé via
  `certificate_is_clean` ; `main.rs` l'injecte dans
  `cache_set_cert_clean` (≙ `a_Tls_certificate_is_clean`,
  `hsts.c:208`).
- **D8 — réentrance `socket_free` (état-interne)** : l'entrée
  `socks` est extraite **avant** le cleanup (≙ `a_Klist_remove`
  premier, `http.c:301`) — les callbacks réentrants ne voient plus
  le socket mort (double `active_conns--` impossible).
- **D9 — doublon `fd_map` (état-interne)** : insertion gardée +
  `warn!` ≙ `assert` amont au lieu d'un remplacement silencieux.
- **D10 — `chain.check` CAPI/DPI (état-interne)** : garde en entrée
  de `capi_ccc_fn`/`dpi_ccc` ≙ `dReturn_if_fail(a_Chain_check)`
  (capi.c:645, dpi.c:652) — op sur lien terminé/invalide = no-op.
- **D11 — `wait` tolérant (wire-visible)** : parsing ≙ `atof`
  (`dlib::strtod`) — `wait 5abc` attend 5 s comme amont au lieu
  d'une attente infinie.
- **D12 — DNS réentrance (état-interne)** : callback invoqué avant
  retrait de l'entrée de file (`dns.c:408-413`) — un re-resolve du
  même host pendant le cb partage le canal dans la même passe
  (y compris sur échec) au lieu d'une requête neuve différée.
- **D13 — octets stagés `io::submit` (état-interne)** : `io.buf`
  restauré quand aucun FD/stream n'existe (≙ `io->Buf` conservé
  amont) — plus de perte silencieuse.
