## A02 — URL, cookies, domaines, HSTS (apply)

Corrections de parité sémantique sur `dillo-net` + `dillo` (rapport
`docs/audits/reports/A02_url-cookies.md`) :

- **D1 — `%xx` tolérant `strtol`** (`decode_hex_str`) : amont valide
  une séquence si `strtol(hex,…,16)` consomme exactement 2 chars —
  espace C ou `+` suivi d'un chiffre comptent (`%+f`→15, `% f`→15),
  `-` donne `val<0` → littéral. Nouveau `decode_hex_octet` verbatim ;
  séquences invalides/incomplètes toujours recopiées littéralement.
- **D2 — `frag_eq` NULL≡""** (`history.rs`) : `URL_FRAGMENT` =
  `NPTR2STR` amont → `http://a.b/` et `http://a.b/#` dédupliquent ;
  un fragment non vide reste distinct.
- **D3 — `LINE_MAXLEN` 4096** (`fgets_lines` partagé dans
  `lib.rs`, utilisé par `cookies.rs` et `hsts.rs`) : `fgets` borne
  chaque lecture à 4095 octets et reparse le reste comme ligne
  suivante — reproduit pour `cookiesrc` et le preload HSTS.
- **D4 — `Cookies_fopen`** (`crates/dillo/src/main.rs`) :
  `~/.dillo/cookiesrc` absent → créé `O_WRONLY|O_CREAT|O_TRUNC`
  (0600 unix) avec `DEFAULT DENY\n` avant lecture, verbatim.
- **D5 — `dStrstrip` ASCII** : `trim()` Unicode remplacé par le
  strip `isspace()` C (ASCII + `\v`) dans les lecteurs
  `cookiesrc`/`hsts` — U+00A0 & co. ne strippent plus.

Tests ajoutés : cas `strtol` lenient dans `decode_*`
(`%+f`/`% f`/`%-f`/`%f `/`%0x`), `frag_eq` NULL≡"" dans
`history`, `cookiesrc_line_maxlen_and_c_strip` (ligne >4095 ne
fait pas sauter les suivantes ; U+00A0 n'est pas strippé).

## A02 — passe 2 (apply)

Corrections de parité sur le jar/serveur `dpi/cookies.c`
(`dillo-dpi::cookies` + `bin dpi-cookies` — rapport
`docs/audits/reports/A02_url-cookies.md`) :

- **D6 — panic `validate_domain` (fonctionnel)** : domaine à 1
  caractère (`Domain=x`) formait un range `1..0` → panic du démon.
  Garde `len < 3` ≙ boucle amont `i<strlen-1` à 0 itération.
- **D7 — `disabled` inversé (fonctionnel)** : `cookiesrc` tout-DENY
  activait le démon et créait `cookies.txt` ; amont
  `Cookie_control_init()!=0` → `exit(1)` avant ouverture. Ordre
  restauré (`bin/cookies.rs`).
- **D8 — `LINE_MAXLEN` 4096** : `fgets_lines` (partagé, rendu `pub`
  dans `dillo-net`) reproduit le découpage `fgets` 4095-octets dans
  `load` et `control_init` — une ligne géante ne fait plus sauter
  les suivantes ni fusionner des champs.
- **D9 — espaces C-locale** : `trim`/`split_whitespace` Unicode →
  strip/split `isspace()` ASCII (`` inclus, U+00A0 non stripé).
- **D10 — expirations tolérantes** : parse `strtol`-préfixe
  (`"99abc"`→99) + borne `int` amont sur `tm_min += secs/60`
  (`mktime`-1 ≙ `i32::MAX` dépassé → expiré, sans panic).
- **D11 — nom vide accepté** : `name`/`value` requis « présents »,
  pas non-vides ≙ `dStrdup("")` amont.
- **D12 — `Max-Age` préfixe** : `3600abc`→3600 ≙ `strtol`.
- **D13 — suffixes `a..com`** : boucle repart après `domain_str++`
  (≙ `p+2`) — plus de `.com` en double ni `com` nu sur hôte
  malformé.
- **D14 — `cookies.txt` 0600 + `FD_CLOEXEC`** (unix) ≙
  `cookies_fopen` amont.
- **D15 — write-fail → exit(1)** : `get_cookie` propage l'échec
  `dsh_write_str` ≙ `ret=1` amont (dpid relance le démon).

Tests ajoutés : `load_empty_name_accepted`, `load_line_maxlen_splits`,
`load_strtol_prefix_expiry`, `load_c_locale_strip`, `validate_domain_
single_char_no_panic`, `get_no_bare_suffix_on_double_dot`,
`max_age_prefix_parsed`, `expiry_minutes_int_overflow_expires` —
15/15 tests `cookies` verts.
