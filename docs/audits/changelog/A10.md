## A10 — plateforme (correctif post-passe 2)

- **`set_viewport_size` endommage tout sur changement**
  (fonctionnel — vestiges en bordure) : l'apparition/disparition
  des scrollbars et le redimensionnement du viewport changeaient
  `vsb_visible`/`hsb_visible`/`view_w`/`view_h` sans émettre de
  damage — la bande de 15 px libérée ou recouverte gardait les
  pixels de la page précédente (typique navigation page
  courte→longue). Amont `adjustScrollbarValues` → `show()/hide()`/
  `resize()` des widgets enfants ≙ `FL_DAMAGE_ALL`.
  `damage_all = true` restauré sur tout changement.
  Régression : `viewport_change_marks_full_damage`.

## A10 — plateforme (saisie in-page — D2 résolu)

- **Focus + clavier des contrôles de formulaire** (fonctionnel —
  saisie impossible dans les entrées/textarea de page, ex. barre
  de recherche Google) : amont les contrôles sont de vrais widgets
  FLTK enfants du viewport — `Fl::focus`/`Fl::handle` leur
  délivrent focus et clavier nativement. Chez nous ils sont
  dessinés par tiny-skia : il manquait tout le sous-système.
  Ajouté : `Canvas.focused` (`Weak`, meurt avec le widget ≙
  destruction de l'enfant), `View::set_focused_resource` ≙
  `Fl::focus` (`set_focused` + damage de l'allocation),
  `Embed::buttonPressImpl` ≙ `take_focus` (press sur entrée
  éditable → focus + consommé ; release ≙ `FL_WHEN_RELEASE` →
  `ui_button` + `queueDraw`), clic ailleurs → défocus ≙ `Fl::focus`
  vers le widget cliqué, routage `KeyboardInput` → ressource
  focusée d'abord puis shell (≙ remontée `handle` FLTK), Ctrl+V ≙
  `Fl::paste` via `clipboard_text`. `SkiaEntryResource` :
  saisie UTF-8 au caret, Backspace/Delete/flèches/Home/End, Enter
  → `emitActivate` ≙ `FL_WHEN_ENTER_KEY_ALWAYS`, caret dessiné ≙
  `input->position()` ; multiline : Enter → `\n`. Boutons :
  `ui_button` ≙ `FL_PUSH`/`FL_RELEASE` (toggle check/radio au
  release, exclusion de groupe, `emitClicked` au release ≙
  `FL_WHEN_RELEASE` ; complex-button idem côté `dw::ui`).
  Régressions : `embed_press_focuses_text_resource`,
  `button_press_clears_focus`, `focused_resource_flags_and_damages`,
  `entry_focus_insert_and_keys`, `entry_readonly_ignores_edits`,
  `entry_max_length_bounds_insert`,
  `multiline_enter_inserts_newline`, `label_button_release_semantics`,
  `check_button_toggles_on_release`, `radio_click_excludes_group`.
